MUTUAL FUND ANALYZER - COMPREHENSIVE FEATURE REPORT

================================================================================
PROJECT OVERVIEW
================================================================================

The Mutual Fund Analyzer is a comprehensive web-based application designed to help Indian investors make informed decisions about mutual fund investments. Built using modern React technology with real-time data integration from MFAPI.in, the platform offers powerful analytical tools, portfolio management capabilities, and sophisticated comparison features. The application provides access to over 40,000 mutual fund schemes across India, enabling users to analyze historical performance, calculate returns, compare funds side-by-side, and track their investment portfolios. With a user-friendly dark-themed interface and proprietary scoring algorithms, this tool serves both novice investors seeking guidance and experienced investors requiring detailed analytics.

================================================================================
1. APPLICATION ARCHITECTURE
================================================================================

The application is built on a robust technical foundation using React 18 with Vite as the build system, ensuring fast development and optimized production builds. React Router v6 handles client-side navigation across six main routes: Home, Portfolio, Compare, Calculator, Fund Details (dynamic routing), and News. The frontend architecture employs a component-based design with reusable UI elements scattered across the Components directory. State management is handled at the application level in App.jsx, maintaining global state for portfolio funds, search results, comparison selections, and UI states. The styling approach uses inline JavaScript style objects with a consistent dark theme (#111827 background) and green accents (#00C853), creating a modern, professional aesthetic. Chart.js with react-chartjs-2 powers all data visualizations, while React Icons provides a comprehensive icon library for UI elements.

6. SIP CALCULATOR
================================================================================

The calculator page houses a powerful Systematic Investment Plan (SIP) calculator that helps users project potential returns on their monthly investments. The interface presents three input parameters: monthly investment amount (in rupees), investment duration (in years), and expected return source. Users can either enter a custom return rate percentage or select a fund from their portfolio to use its actual 1-year return. When a fund is selected, the calculator displays the fund's category, risk level, and past 1-year return, providing context for the projection. Upon calculation, three results are displayed: Total Investment (the sum of all monthly investments over the period), Estimated Returns (the profit earned), and Total Maturity Value (principal plus returns). A pie chart visualization breaks down the final amount into two segments: blue for the investment amount (principal) and green for the returns earned (profit), with percentage labels and interactive tooltips showing exact rupee values. The calculator uses the standard SIP compound interest formula: M = P × [{(1+r)^n - 1} / r] × (1+r), where M is the maturity amount, P is monthly investment, r is monthly interest rate, and n is the number of months. This tool helps investors understand the power of compounding and plan their investment strategies effectively.

10. INVESTOR SCORE SYSTEM
================================================================================

The investor score is a proprietary comprehensive rating system that evaluates mutual fund performance on a 0-100 scale using a sophisticated five-factor analysis. The scoring methodology allocates 100 points across five metrics: 1-Year Return (25 points) measures recent performance with a range of -50% to +50%, 3-Year CAGR (25 points) assesses medium-term consistency with a range of -20% to +40%, 5-Year CAGR (25 points) evaluates long-term growth trajectory over the same range, Volatility (15 points) rewards stability by penalizing higher standard deviation of daily returns, and Consistency (10 points) measures the percentage of trading days with positive returns over the last 12 months. Each metric is normalized to its point allocation, with specific scoring formulas ensuring fair comparison across different fund types. The final score maps to six ratings: Excellent (85-100, green #00C853), Very Good (70-84, light green #4CAF50), Good (55-69, lime #8BC34A), Average (40-54, amber #FFC107), Below Average (25-39, orange #FF9800), and Poor (0-24, red #F44336). The investor score appears throughout the application: on fund cards in the portfolio, in the comparison table, and prominently on the fund details page with a full performance breakdown. This scoring system provides investors with a quick, reliable metric to assess fund quality without needing to analyze complex data manually.

12. API INTEGRATIONS
================================================================================

The application integrates with two primary APIs to deliver real-time data and news content. MFAPI.in, a free and open API for Indian mutual fund data, provides access to over 40,000 schemes without requiring authentication. The "Get All Schemes" endpoint (https://api.mfapi.in/mf) returns a complete list of mutual fund schemes with scheme codes and names, which the application caches for search functionality. The "Get Fund Details" endpoint (https://api.mfapi.in/mf/{schemeCode}) retrieves comprehensive information for a specific fund, including metadata (scheme name, fund house, category) and historical NAV data (date and NAV values). The application transforms this raw data into a standardized format, calculating derived metrics like risk level, 1-year return, and investor score on the fly. Marketaux API provides the financial news feed, requiring an API key stored as an environment variable (VITE_NEWS_API_KEY). The endpoint fetches the top 10 India-focused financial news articles with title, description, and publication date. Error handling wraps all API calls with try-catch blocks, displaying user-friendly error messages and loading states during data fetching. This dual-API approach ensures the application provides both comprehensive fund data and relevant market news, creating a complete investment research platform.

13. TECHNICAL IMPLEMENTATION
================================================================================

The project follows a well-organized directory structure separating concerns across components, pages, services, utilities, and styles. The main App.jsx serves as the application root, handling routing setup and global state management including portfolio funds, search results, and comparison selections. Thirteen reusable components in the Components directory handle specific UI elements like fund cards, charts, modals, and navigation. Six page components in the pages directory represent the main routes, each managing its local state for user interactions. Two service modules (fundService.js and newsService.js) encapsulate API logic, providing clean functions for data fetching. Six utility modules implement core calculations: calculateCAGR.js for compound annual growth rate, calculateInvestorScore.js for the proprietary scoring system, calculateReturn.js for simple returns, calculatePeriodReturn.js for specific time periods, calculateScore.js for search relevance, and getRisk.js for risk classification from categories. Styling uses a combination of inline JavaScript style objects in separate style files (homeStyles.js, navbarStyles.js, styles.js) and CSS files (Home.css, App.css, index.css), maintaining consistency with the dark theme. Performance optimizations include Promise.all for parallel API calls, efficient filtering algorithms, and responsive grid layouts with CSS. The build system uses Vite for fast development iteration and optimized production builds, with ESLint maintaining code quality throughout development.
